Bloque 3 · Fundamentación atómica

Primero: elevar al cuadrado

Elevar al cuadrado es multiplicar algo por sí mismo. Es la única operación que vas a usar una y otra vez.

n² = n · n
Pasos
  1. Mira todo lo que está dentro del paréntesis.
  2. Eleva al cuadrado el número y también la letra.
  3. Escribe el resultado.
Ejemplo rápido: (3x)² = 3² · x² = 9x²  (no es 3x²).
Bloque 4 · Marco teórico y modelo conceptual

¿Qué es la suma por diferencia?

Es multiplicar dos paréntesis casi iguales: uno con + y otro con −. El resultado siempre es “el primero al cuadrado menos el segundo al cuadrado”.

(a + b)(a − b) = a² − b²

Regla en 3 pasos

  1. Identifica a (el término que se repite igual) y b (el que cambia de signo).
  2. Eleva al cuadrado cada uno.
  3. Réstalos: a² − b².

Glosario rápido

a
primer término, igual en los dos paréntesis
b
segundo término, con signos opuestos
a²
el cuadrado del primero
b²
el cuadrado del segundo

¿Por qué funciona? (demostración)

(a+b)(a−b) = a·a − a·b + b·a − b·b = a² − ab + ab − b². Los términos del medio se cancelan: queda a² − b².

Mira el área

Un cuadrado de lado a al que le quitas un cuadrado de lado b tiene área a² − b². Si cortas y acomodas, forma un rectángulo de base (a+b) y altura (a−b): la misma área.

Practica con ayuda

Nivel 0 · Base operativa

Calcula (4)² y (3x)²

4² = 4·4 = 16.
(3x)² = 3²·x² = 9x².

16 y 9x²

Nivel 1 · Aplicación directa

Desarrolla (3x + 4)(3x − 4)

1) a = 3x, b = 4.
2) a² = (3x)² = 9x²; b² = 4² = 16.
3) Resta: a² − b².

9x² − 16
Desarrolla (x + 2)(x − 2)

a = x, b = 2 → x² − 2² .

x² − 4

Nivel 2 · Combinación de operaciones

Factoriza 25m² − 36n²

1) Raíces: √(25m²) = 5m y √(36n²) = 6n.
2) Aplica la fórmula al revés: (a+b)(a−b).

(5m + 6n)(5m − 6n)
Simplifica (x² − 4) / (x + 2)

1) Factoriza arriba: x² − 4 = (x+2)(x−2).
2) Cancela (x+2) con el de abajo (x ≠ −2).

x − 2

Nivel 3 · Casos especiales y desafíos

Desarrolla (2xy + 3y²)(2xy − 3y²)

a = 2xy → a² = 4x²y². b = 3y² → b² = 9y⁴.

4x²y² − 9y⁴
Calcula 52 × 48 sin calculadora

52 = 50 + 2 y 48 = 50 − 2.
Entonces 50² − 2² = 2500 − 4.

2496
Bloque 7 · Práctica autónoma, errores comunes y evaluación

Cuidado con estos errores

Error 1: escribir 3x² en lugar de 9x². El 3 también se eleva: (3x)² = 9x².
Error 2: poner un “+” en el resultado (a² + b²). Es siempre una resta.
Error 3: confundirlo con (a − b)². Aquí los paréntesis tienen signos distintos; no hay término del medio.
